# Задание 3.2

Программа генерирует случайные IP-адреса, определяет принадлежность каждого адреса подсети шлюза и выводит статистику распределения пакетов между своей подсетью и другими сетями.

## Назанчение файлов

- `main.c` - обработка аргументов командной строки и определение принадлежности IP-адресов подсети.
- `back.c` - функции преобразования IP-адресов, обработки маски подсети и генерации случайных IP-адресов.
- `front.c` - функции вывода информации о пакетах и итоговой статистики.
- `header.h` - структуры и объявления функций.
- `Makefile` - сборка, очистка и запуск тестов.
- `tests/test_program.py` - тесты на Python `unittest`.

## Сборка

Для сборки проекта необходимо выполнить команду в папке проекта:

```bash
make
```

После успешной компиляции будет создан исполняемый файл `code`.

Для удаления объектных файлов и исполняемого файла используется команда:

```bash
make clean
```

## Запуск программы

Программа запускается из командной строки:

```bash
./code <IP_шлюза> <маска> <N>
```

Аргументы:

- `IP_шлюза` — IPv4-адрес шлюза.
- `маска` — маска подсети в формате `/24` или десятичном формате `255.255.255.0`.
- `N` — положительное целое число, задающее количество генерируемых пакетов.

Примеры запуска:

```bash
./code 192.168.1.1 /24 100
```

```bash
./code 192.168.1.1 255.255.255.0 100
```

1. Программа получает аргументы командной строки.
2. Проверяет количество аргументов и значение N.
3. Преобразует IP-адрес в 32-битное число.
4. Проверяет корректность маски подсети.
5. Вычисляет адрес подсети шлюза с помощью побитовой операции И.
6. Генерирует N случайных IPv4-адресов.
7. Для каждого IP-адреса определяет его принадлежность подсети шлюза.
8. Выводит информацию о каждом пакете.
9. Подсчитывает количество и процент пакетов, относящихся к своей подсети и другим сетям.

Принадлежность IP-адреса подсети определяется условием:

```c
(ip & mask) == (gateway & mask)
```

Если условие выполняется, адрес принадлежит своей подсети. В противном случае он относится к другой сети.

## Пример вывода

Пример запуска:

```bash
./code 192.168.1.1 /24 5
```

Возможный результат:

```text
1. 192.168.1.25 -> своя подсеть
2. 10.45.12.8 -> другая сеть
3. 172.16.5.10 -> другая сеть
4. 192.168.1.100 -> своя подсеть
5. 8.8.8.8 -> другая сеть

Своя подсеть: 2 (40.00%)
Другие сети: 3 (60.00%)
```

IP-адреса генерируются случайным образом, поэтому результат каждого запуска может отличаться.

## Обработка ошибок

В программе предусмотрена обработка следующих ситуаций:

- Неправильное количество аргументов командной строки.
- Неположительное количество пакетов.
- Некорректная маска подсети.

В случае обнаружения ошибки программа выводит соответствующее сообщение и завершается с кодом `1`.

При успешном выполнении программа завершается с кодом `0`.

## Автоматизированное тестирование

Для проверки корректности работы программы используется фреймворк Python `unittest`.

Перед выполнением тестов автоматически компилируются исполняемый файл программы и динамическая библиотека с тестируемыми функциями.

### Реализованные тесты

| Тест | Назначение |
|---|---|
| `test_ip_to_uint` | Проверка преобразования IPv4-адресов в числовой формат |
| `test_prefix_masks` | Проверка масок подсети в формате `/N` |
| `test_dotted_masks` | Проверка масок в десятичном формате |
| `test_invalid_masks` | Проверка обработки некорректных масок |
| `test_no_arguments` | Проверка запуска без аргументов |
| `test_wrong_number_of_arguments` | Проверка неправильного количества аргументов |
| `test_nonpositive_packet_count` | Проверка некорректного количества пакетов |
| `test_invalid_mask_in_main` | Проверка некорректной маски при запуске программы |
| `test_all_packets_in_own_subnet_with_zero_mask` | Проверка принадлежности всех адресов подсети `/0` |
| `test_dotted_mask_in_main` | Проверка запуска программы с десятичной маской |

### Запуск тестов

Для запуска всех тестов используется:

```bash
make test
```

Альтернативный способ:

```bash
python3 -m unittest discover -s tests -p "test_*.py" -v
```

При успешном выполнении всех тестов ожидается сообщение:

```text
Ran 10 tests

OK
```

Если проверка не проходит, фреймворк выводит информацию о неуспешном тесте и причине ошибки.
