# Задание 4.3

Программа для хранения и редактирования контактов. Контакты находятся в оперативной памяти и упорядочиваются в AVL-дереве по фамилии, затем имени, затем отчеству. Для совпадающих Ф.И.О. сохраняется порядок добавления.

Программа поддерживает:

- добавление контакта;
- просмотр отсортированного списка;
- просмотр подробных данных контакта;
- редактирование контакта;
- удаление контакта.

Для контакта можно хранить фамилию, имя, отчество, место работы, должность, до трёх телефонов, до трёх адресов электронной почты, Telegram, VK и другие социальные сети.

## Назанчение файлов

- `main.c` - создание телефонной книги, запуск меню и освобождение памяти.
- `back.c` - вставка, поиск по индексу отсортированного списка, редактирование, удаление, балансировка и очистка.
- `front.c` - меню, чтение и проверка ввода, вывод контактов.
- `header.h` - структуры и объявления функций.
- `Makefile` - сборка, очистка и запуск тестов.
- `tests/test_program.py` - тесты на Python `unittest`.

## Сборка

Для сборки проекта необходимо выполнить команду в папке проекта:

```bash
make
```

После успешной компиляции будет создан исполняемый файл `code`.

Для удаления объектных файлов и исполняемого файла используется команда:

```bash
make clean
```

## Запуск программы

Программа запускается из командной строки:

```bash
./code
```

После запуска доступно меню:

```text
====ТЕЛЕФОННАЯ КНИГА====
1. Добавить контакт
2. Показать список
3. Просмотреть контакт
4. Редактировать контакт
5. Удалить контакт
0. Выход
```

Для просмотра, изменения или удаления контакта сначала показывается отсортированный список, затем необходимо ввести его номер (начиная с 1).

### Правила ввода

- Фамилия и имя обязательны и допускают только буквы (ASCII A–Z/a–z или байты не-ASCII, что позволяет вводить кириллицу).
- Отчество необязательно; к нему применяются те же ограничения на символы.
- Номера телефонов могут содержать только цифры; пустое поле допускается.
- Остальные поля необязательны. Проверка формата адресов электронной почты и ссылок социальных сетей не выполняется.

### Реализация дерева

Для сортировки используется `strcoll()`; результат сравнения зависит от текущей локали. При совпадении фамилии, имени и отчества используется порядковый номер вставки `order`. AVL-дерево после добавления и удаления узлов поддерживает высоту и выполняет повороты при нарушении баланса.

`get_contact()` возвращает контакт по индексу в отсортированном списке. Меню показывает номера начиная с единицы.

## Автоматизированное тестирование

Для проверки корректности работы программы используется фреймворк Python `unittest`.

Перед выполнением тестов автоматически компилируются исполняемый файл программы и динамическая библиотека с тестируемыми функциями.

### Реализованные тесты

| Тест | Назанчение |
|---|---|
| `test_empty_book` | Пустая книга и отсутствие контакта |
| `test_add_contact` | Добавление и сохранение данных |
| `test_sort_by_surname` | Сортировка по фамилии |
| `test_sort_by_name_and_patronymic` | Сортировка по имени и отчеству |
| `test_duplicate_names_preserve_insertion_order` | Порядок контактов с одинаковыми Ф. И. О. |
| `test_edit_contact_changes_sort_position` | Редактирование и повторная сортировка |
| `test_delete_only_contact` | Удаление единственного контакта |
| `test_delete_middle_contact` | Удаление контакта |
| `test_avl_balancing_after_many_insertions` | Балансировка и высоты узлов после 100 вставок |
| `test_cli_exit` | Завершение программы через меню |
| `test_cli_empty_list` | Просмотр пустой книги |
| `test_cli_invalid_command` | Обработка неизвестной команды |
| `test_cli_add_view_delete` | Добавление, просмотр и удаление через меню |
| `test_cli_invalid_required_name_and_phone` | Повторный ввод при ошибочных фамилии и телефоне |

### Запуск тестов

Для запуска всех тестов используется:

```bash
make test
```

Альтернативный способ:

```bash
python3 -m unittest discover -s tests -p "test_*.py" -v
```

При успешном выполнении всех тестов ожидается сообщение:

```text
Ran 14 tests

OK
```

Если проверка не проходит, фреймворк выводит информацию о неуспешном тесте и причине ошибки.
